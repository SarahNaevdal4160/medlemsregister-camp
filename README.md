# medlemsregister-camp

## Ett problem vi löste 

När vi arbetade med medlemsregistret fick vi problem när vi skulle hämta ändringar från main till vår egen gren. Git hittade en konflikt i src/Main.java, eftersom ändringarna i filen inte kunde slås ihop automatiskt. Vi löste konflikten och kontrollerade sedan att programmet fungerade genom att starta det. Programmet visade medlemsregistrets välkomsttext och medlemsnummer som förväntat. Till sist sparade vi lösningen i en commit och pushade vår gren till GitHub.
